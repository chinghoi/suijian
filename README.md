# 随剪 (SuiJian)

专为 **DJI 大疆（无人机 / Action / Pocket / Nano）** 打造的轻量级 4K 10-Bit HDR 视频初筛与极速出片工具。

## 🎯 适用人群

* **无人机航拍创作者**：飞完降落后，需要快速查看几十 GB 的 4K 60fps 10-Bit D-Log M / HLG 素材，不想打开庞大卡顿的专业后期软件。
* **运动相机 / 随身 Vlog 创作者**：使用 Osmo Action、Pocket 或 Nano 随拍，拍完插卡即剪，一键生成卡点视频直接发布。
* **现场作业与户外摄影师**：需要在拍摄现场随时插拔 SD 卡，甚至剪到一半需要随时拔掉相机去补录镜头，希望系统能“断点续接、防灾防误拔”。
* **触控屏 / 平板笔记本用户**：在 Surface、触控屏或移动设备上使用手指即可流畅切分、撤销、回放。

## ✨ 实现了什么

### 1. 极致硬解与 4K 10-Bit HDR 原画质
* **硬件渲染**：基于 Qt Quick 6 (RHI / Metal 硬件加速)，4K 高码率预览零丢帧。
* **母带级输出**：底层调用 FFmpeg 硬件编码器，原生输出 **HEVC 10-Bit (p010le) · BT.2020 · ARIB STD-B67 (HLG)** 65Mbps 电影母带，无损保留动态范围与色彩细节。

### 2. 本地 AI 智能初筛与快速切分
* **静音剔除**：基于音频波形能量分析，自动切除长段无声与废镜头。
* **视觉与抖动初筛**：识别高美感画面与高光片段，过滤起飞、降落与剧烈抖动废片。
* **多种画幅适配**：一键切换 16:9 横屏母带或 9:16 竖屏短视频。

### 3. 可推出设备防误拔与断点续剪（独创韧性防护）
* **随时暂停拔卡**：剪辑或 AI 初筛处理过程中，可点击“安全拔卡”，随时拔掉 Nano/相机去继续录像，进度自动存盘。
* **防误拔熔断保护**：存储卡意外拔掉时应用不崩溃，工程安全冻结，插回设备自动无缝续接。
* **资产变动审计（增/删/改）**：
  * **增**：断开期间新录制的视频，**不自动强插**时间线，避免破坏成片节奏。
  * **删**：原视频若在相机内被删除，时间线对应片段**自动标红警示失效**，防止合成损坏。
  * **改**：文件被覆写修改**等同于删除**，失效片段可一键清理。

### 4. 撤销重做与触控屏交互
* **双指轻点撤销**：触控屏支持双指轻敲（Two-finger Tap）撤销，剪映 / Procreate 同款操作手感。
* **大拇指触控区**：界面配备醒目的大热区 `↩ 撤销` 与 `↪ 重做` 按钮，自动状态置灰防误触。
* **键盘全快捷键**：支持 `Cmd+Z` / `Ctrl+Z` 撤销，`Cmd+Shift+Z` / `Ctrl+Y` 重做，`Space` 播放，`B` 切割，`Del` 删除。

### 5. 跨平台响应式布局与全套图标资产
* 自适应宽屏桌面与触控模式；
* 规范切图套件：macOS ICNS、Windows 多分阶 ICO、iOS 全铺满、Android Adaptive 分层图标。

## 🚀 快速上手

### 环境需求
* Python 3.10+
* FFmpeg (已配置于系统环境变量)

### 运行方式
```bash
# 1. 克隆仓库
git clone https://github.com/chinghoi/suijian.git
cd suijian

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动应用
python3 main.py
```
