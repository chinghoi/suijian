# 随剪 (SuiJian)

专为 **懒得剪辑的人** 设计的 DJI 视频快速初筛与出片工具。

拍了一堆航拍或 Vlog 视频堆在卡里懒得剪？「随剪」的核心就是帮你 **一键筛掉所有垃圾无效片段，只留精彩瞬间**。

## 适用人群

* **拍完视频懒得剪的人**：卡里几十 GB 视频放了好几个月，一想到要打开臃肿复杂的剪辑软件就头疼；
* **只想快速挑出好看镜头的人**：不需要复杂的调色特效，只想快速把晃动废片扔掉、留下精华直接出片发朋友圈或社交平台；
* **随时拔卡补拍的随摄党**：初筛到一半随时拔掉相机去补录镜头，插上还能接着处理，不怕误拔丢失进度；
* **专业后期剪辑师**：想在几分钟内完成大量航拍/活动原片的初步筛选，并直接导出 FCPXML 工程进达芬奇调色精修。

## 核心特性

### 1. 真实拍摄朝向智能自适应与双端手动矫正
* **多数决智能自适应**：自动解析相机元数据与真实陀螺仪朝向，统计当前成片中横屏与竖屏镜头的数量对比。若竖屏素材占多数，成片母带自动设定为 9:16 竖屏；反之设定为 16:9 横屏，彻底杜绝黑边与形变；
* **双端一键 90° 矫正**：桌面端与移动端检查器均配备「↻ 矫正真实方向」按键与标签，点击即实时翻转朝向，自动触发多数决重计并支持撤销恢复（Undo/Redo）。

### 2. 专业后期 FCPXML 工程与结构化元数据清单导出
* **FCPXML 1.9 专业工程直导**：秒级生成标准 Final Cut Pro XML 工程文件，无缝导入 DaVinci Resolve（达芬奇）或 Final Cut Pro，保留时间线上精确入出点、多轨相对时间偏移与原片文件引用，免去重复粗剪；
* **多格式元数据清单**：支持导出结构化 `.json` 元数据与带 UTF-8 BOM 的 `.csv` 表格清单（可直接在 Excel / Numbers 中双击查看），归档镜头编号、拍摄时间、色彩位深、截取时长与语音字幕文本；
* **独立 SRT 字幕**：时间线语音转录字幕支持一键导出标准 `.srt` 外挂字幕文件。

### 3. 自动过滤无效废片与多模态智能初筛
* **晃动与废片切除**：自动切掉镜头朝地、剧烈晃动、长段无声以及发呆无用的垃圾镜头；
* **四大智能剪辑模型策略**：
  * 口播智能粗剪（废句重录消除、保留连贯呼吸声、自动生成字幕）；
  * 视觉审美优先（保留平稳优质构图、过滤剧烈抖动）；
  * 语音静音切分（剔除长时间无声死寂片段）；
  * 深度多模态综合混合（多模态高光精选成片）；
* **成片节奏与时长自选**：支持“宽松完整保留（仅过滤废片）”、“标准成片节奏（3~5分钟）”与“短视频快节奏（1~2分钟）”。

### 4. 随时拔卡录像，插上断点续剪
* **随拔随拍**：处理中随时点击“安全拔卡”，拔走相机去补拍录像，断点自动存盘；
* **不怕误拔**：意外扯掉数据线绝不闪退报错，插回卡后自动接着断点继续；
* **外设热插拔感知**：实时监听 USB 与 SD 卡挂载状态，自动识别 DJI、GoPro、Sony、Canon 盘符，自动过滤 `.LRF` / `.LRV` 代理小文件。

### 5. 原生 4K 10-Bit HDR 原画质直出
* **硬件级高码率预览**：基于 Qt Quick 硬件加速管道，流畅预览 DJI 4K 60fps 10-Bit (D-Log M / HLG) 大码率素材，不卡顿不掉帧；
* **原生 4K HDR 母带压制**：符合 YouTube / B站 原生 4K60 HDR 审核标准（HEVC Main 10 / BT.2020 / HLG / 65Mbps）。

### 6. 移动端与触控响应式双模架构
* **多端自适应**：一套代码原生支持电脑端三栏专业工作台与移动端/平板触控流体布局；
* **移动端初筛控制中心**：内嵌监视器待机引导、源片独立预览、完整剪辑微调检查器以及后台初筛进度管理；
* **触控大热区与手势**：配备底部拇指操作栏与大尺寸触控卡片，支持双指轻点 (Two-finger Tap) 撤销等快捷手势。

### 7. Apple HIG 规范原生视觉与深色模式
* **macOS 原生坞标**：遵循 Apple Human Interface Guidelines 规范，适配 824x824 黄金比例圆角矩形，留出 100px 呼吸边距与双层原生阴影，视觉大小与系统原生 App 统一；
* **深色模式沉浸设计**：深度适配 macOS Dark Aqua 原生暗色标题栏，全界面去表情化设计，严谨专业。

## 下载与运行

GitHub Actions 会打出这些包，也可在 [Releases](https://github.com/chinghoi/suijian/releases) 下载：

* macOS: `SuiJian-Native-macOS.dmg`（包里带有 Qt，分析和导出仍要本机 `ffmpeg` / `ffprobe`）
* Windows: `SuiJian-Native-Windows.zip`（解压后运行 `随剪.exe`，包里带有 Qt，同样需要本机 FFmpeg）
* Linux: `SuiJian-Native-Linux-x64.tar.gz` 里只有可执行文件。系统里要有兼容的 Qt 6、Qt Quick 和 `ffmpeg` / `ffprobe`，否则打不开或不能处理视频。

本地编译需要 Qt 6（Core、Gui、Quick、QuickControls2、Multimedia）、CMake 3.20+、C++17，以及运行时能调用的 `ffmpeg` 和 `ffprobe`。HDR 转 SDR 还需要带 `zscale` 和 `tonemap` 的 FFmpeg；没有这两个滤镜时导出会停下来说明原因。

```bash
cmake -B build
cmake --build build -j
./build/随剪.app/Contents/MacOS/随剪    # macOS
./build/DJIEditor                      # Linux
```

## 路线图 (Roadmap)

### 已完成特性
- [x] **音频管道 10 倍极速提速**：采用 `-map 0:a:0` 高速音频流抽取与本地 16kHz WAV 瞬时 VAD 检测，跳过 5GB+ 4K 60fps 视频画面的漫长解复用，大幅缩短筛选等待时间。
- [x] **任务状态显式反馈与全流程交互互锁**：动态呼吸脉冲徽章（运行中/暂停/待机就绪）、精确实时百分比与步骤反馈；初筛进行中自动锁定置灰所有参数选项与按钮，防止误触。
- [x] **宽松保留模式时长百分比自定义**：支持 30%、50%、75%、100% 快捷档位与连续百分比滑杆，实时测算并展示预期成片时长。
- [x] **外设热插拔感知模块**：自动检测 USB / SD 卡挂载，适配 DJI、GoPro、Sony、Canon 设备目录，自动过滤 `.LRF` / `.LRV` 等代理小文件。
- [x] **专业工程与元数据导出**：支持导出 Final Cut Pro (`.fcpxml` 1.9，达芬奇直通)、`.json` 结构化元数据清单与 `.csv` (Excel / Numbers) 镜头明细表。
- [x] **真实朝向智能判定与矫正**：多数决机制自动自适应成片画幅（16:9 / 9:16），双端支持一键 90° 旋转矫正与撤销重做。
- [x] **移动端 AI 初筛控制中心**：移动端流体布局、监视器待机引导、源片独立预览与完整检查器微调交互。
- [x] **Apple HIG 标准 macOS 坞标**：标准 824x824 呼吸边距圆角矩形与双层原生阴影。

### 近期规划
- [x] **3D LUT**：导出面板可选择标准 `.cube`，仅在 8-bit SDR 成片上通过 FFmpeg `lut3d` 套用。未选择时不影响原来的 HLG 母带路径。
- [x] **音乐重音卡点**：可导入自己的音乐，或使用程序生成的一段示范鼓点。剪切点按成片时间落到重音上，不会把素材入点改到音乐的时间码。导出时成片音轨换成这首音乐，镜头原声不进入成片。没有内置曲库。
- [ ] **Android APK**：`scripts/build_android.sh` 需要本机的 Android SDK 和 Qt Android 套件。这里没有打出 APK。

### 中期规划
- [x] **朋友圈 / 小红书文案**：按镜头数量和时长生成文案，弹窗里可以复制，并截一张时间线第一段入点附近的关键帧。不识别画面里是什么。
- [x] **剪映草稿**：导出目录里的 `draft_content.json` 与 `draft_meta_info.json`，时间单位是微秒，素材宽高用探测到的画面。还没有在剪映客户端里打开验证，需要自行拷进剪映草稿目录。
- [ ] **iOS / TestFlight**：`scripts/generate_xcode.sh` 只能在已安装 Qt iOS 套件的 macOS 上生成 Xcode 工程。没有归档，也没有提交 TestFlight。

### 远期规划
- [x] **起承转合重排**：至少 3 个镜头时，最短的放开头，最长的放在高潮，次短的放结尾，其余保持原来的先后。这是时长规则，不是剧情理解。
- [x] **按词语留下镜头**：匹配文件名、路径和已有字幕里的词，例如文件名含「猫咪」就能被「只留猫咪特写和夕阳海边」留住。不看画面内容。
